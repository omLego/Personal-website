Arduino Vocabulary Game

This is an interactive English learning game powered by Arduino. It helps users learn the positive and negative meanings of English words correctly through gameplay.

Hardware Components

  • Arduino Nano microcontroller acting as the core brain of the system.
  • OLED screen to display English words and game score feedback.
  • Dual pushbuttons and a key switch for user input and selecting answers.
  • Dual LEDs providing visual feedback for correct or incorrect answers.
  • Audible buzzer providing sound alerts during gameplay.

How the Game Works

The player uses the pushbuttons and key switch to answer whether the displayed English word has a positive or negative meaning.

Game Feedback

When the player gives a correct answer, the green LED lights up and a success tone plays; for an incorrect answer, the red LED triggers along with a buzzer alert.

Device Interface

All electronic components are compactly assembled and housed in a custom enclosure designed for easy handheld or desktop use.
