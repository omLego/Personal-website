Arduino Vocabulary Game

An interactive hardware-based English learning game engineered to make vocabulary practice engaging. Powered by an Arduino Nano, the device challenges players to categorize words through physical inputs while providing real-time audio-visual feedback.

How It Works & Hardware

  • Microcontroller Core: Controlled by an Arduino Nano that processes user inputs and manages game logic.
  • Visual Interface: An OLED screen displays English words from selected categories.
  • User Input: Players use a toggle switch to navigate and dedicated tactile buttons to categorize words.
  • Active Feedback: Correct and incorrect answers trigger specific LEDs. A buzzer provides audible alerts for immediate reinforcement.
